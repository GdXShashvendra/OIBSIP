# 🎙️ Python Voice Assistant

A beginner-friendly Python voice assistant that can listen to spoken commands and respond using text-to-speech.

## 🚀 Features

- 🎤 Voice input using microphone
- 🗣️ Text-to-speech responses
- 👋 Greeting response
- 🕐 Current time
- 📅 Current date
- 🔎 Google web search
- 🌐 Open Google
- ▶️ Open YouTube
- ❌ Exit command
- ⚠️ Graceful error handling

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser
