# 💬 Python Chat Application

A real-time multi-user chat application built with Python sockets,
Tkinter and SQLite.

## Features

- Real-time messaging
- Multiple clients
- User registration
- User login
- SQLite database
- Multiple chat rooms
- Create rooms
- Join rooms
- Message timestamps
- Message history
- Graceful disconnection
- Emoji shortcodes
- GUI interface
- Localhost networking

## Technologies

- Python
- Socket Programming
- Threading
- Tkinter
- SQLite
- JSON
