# 🌤️ Weather App

A Python GUI weather application that fetches real-time weather information and forecasts using the OpenWeatherMap API.

## 🚀 Features

- Search weather by city
- Current temperature
- Celsius / Fahrenheit conversion
- Feels-like temperature
- Humidity
- Wind speed
- Weather condition
- Weather icons
- Next 6 forecast periods
- 5-day forecast
- Unit toggle
- Network error handling
- Invalid API key handling
- City-not-found handling
- Empty input validation

## 🛠️ Technologies

- Python
- Tkinter
- Requests
- Pillow
- OpenWeatherMap API
